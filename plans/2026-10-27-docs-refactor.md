# Docs refactor: less duplication, easier navigation

## Prompts

- 2026-10-27: "commit it and continue with docs refactor. Currently, reading docs is complex. It is beucase there are a lot of duplications and unnecessary sentences. I want it you to make it more understandable. However, no need the eliminate technical explanations. Also, we may need to rewrite the architecture. Analyze the repo and rewrite the docs. Make navigating more easy across the repo."

## Analysis (before)

14 pages, about 3500 lines, plus a 210-line README.

- **Duplicated topics.** Each of these was explained in 3–5 places:
  - install, first run and GUI display: README, getting-started, docker, cli-reference;
  - parameter precedence: README, cli-reference, generators, maps;
  - doc index: README, docs/README;
  - repo layout: README, architecture, Copilot instructions (stale there);
  - map pipeline order: architecture, maps, generators;
  - heights: maps, geometry, opendrive, scene, architecture;
  - ground mesh: maps, scenarios;
  - lane tapers and advisory speeds: geometry, opendrive.
- **Stale material.**
  - `implementation-guide.md` is a walkthrough of the 2026-10-19 maps branch. It uses `git diff` steps, old node counts and `out/try/`.
  - The architecture module map missed `validate/clearance.py`, `validate/dynamics.py`, `metrics/network.py`, `geometry/grade_separation.py` and two transforms.
  - The Copilot layout listed modules that no longer exist (`opendrive/elevation.py`, `opendrive/geometry.py`).
  - The CLI overview missed `separate`.
- **History mixed into reference text.** "Stage C8", "fixed in stage C8", "the removed manhattan generator", "Next steps".
- **Gaps.** `maps.md` had no parameter tables for terrain, elevation and population. They only existed in the stale walkthrough.

## Decisions

- User: rewrite the docs for readability and navigation without dropping technical explanations. The architecture page may be rewritten.
- Claude: each topic gets one home page, and other pages link to it instead of repeating it.
- Claude: lsystem moves to its own page. It was 80 % of `generators.md`.
- Claude: heights and the 3D scene get their own pages. Their content was split across four pages.
- Claude: stage labels and "fixed in …" notes are removed from the reference text. The project history table in `development.md` links the plans instead.
- Claude: `docs/implementation-guide.md` moves to `plans/2026-10-19-maps-walkthrough.md` as a historical record, since it describes a past branch. Its parameter tables move into `maps.md`.
- Claude: `runs/README.md` is generated by `runs/make_readme.py` from the run folders, so it is not rewritten by hand.
- Claude: the Copilot instructions' repo layout is updated to the real modules, since agents read it.
